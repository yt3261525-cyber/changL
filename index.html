📖 操作指南与超实用技巧

1. 个人专属备注：在卡片下方的备注栏输入账号、Token 或签到要求，自动本地保存，仅自己可见；点击 👁️ 可开启隐私防窥遮罩。

2. 每日签到打卡：签到类站点带有打卡按钮，每天打卡一目了然，顶部进度条实时更新，支持「⏰ 待签到」极速筛选。

3. 客户端接入代码：点击 API 旁的【配置】按钮，即可查看 OpenAI / Cherry Studio / NextChat 等客户端对应格式。

4. 极速连通测速：点击【测速】按钮即可实时检测该 API 在当前网络下的延迟情况。

5. 多端备份防丢：在【设置】中导出备份或手机扫码，即可一秒同步到新手机或平板。
